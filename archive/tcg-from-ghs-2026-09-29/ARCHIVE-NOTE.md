Server backup preserved on 2026-09-29 for historical reference. These files
are not loaded by the active Chronicles TCG application.

The 233 original files remain unchanged in the local private archive. This
repository copy has the same file contents; the note is the only added file.
SHA-256 comparison passed for every copied file before commit.

or populated local `config.js`. The configuration files contain only empty or
demonstration values. `config.example.js` documents an anon client key and a
placeholder, not a usable project key.

The deployment workflow explicitly excludes `/archive/`; these materials are
kept in Git for reference and are not sent to the live site.
