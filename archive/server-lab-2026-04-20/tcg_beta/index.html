Guide rapide du TCG

Bienvenue dans le Trading Card Game ! Voici quelques infos utiles :

  • Objectif : collectionner toutes les cartes des différents sets.
  • Classes : chaque carte appartient à une classe (comme Guerrier, Mage, Voleur...).
  • Raretés : Common, Rare, Epic, Legendary, Mythical — plus la rareté est élevée, plus les chances de l’obtenir sont faibles.
  • Taux de drop estimés : Common ~70 %, Rare ~20 %, Epic ~7 %, Legendary ~2 %, Mythical ~1 %.
  • Boosters : ouvrez un booster pour obtenir plusieurs cartes aléatoires. Faites glisser le coin pour l’ouvrir !

Bon jeu ! 👾
